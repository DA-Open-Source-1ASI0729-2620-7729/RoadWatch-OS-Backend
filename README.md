# RoadWatch OS Backend

## Technologies

- Java 17
- Spring Boot 4.1.2
- Spring Data JPA
- MySQL
- SpringDoc OpenAPI
- Swagger UI
- Maven

## Architecture

Domain-Driven Design

## Bounded Contexts

- Identity & Access Management
- Subscription Management
- Project Management
- Environmental Monitoring
- Incident & Mitigation Management
- Document & Evidence Management
- Reports & Compliance Management

## Git

`main` is reserved for the final stable version.

`develop` is the integration branch.

`ft-*` branches are used to develop each bounded context.
